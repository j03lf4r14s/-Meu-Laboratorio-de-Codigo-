O que o gerenciador garante
  • O código é gravado como texto literal. Nada é formatado, corrigido, otimizado ou reorganizado.
  • Cada código tem aba, registro e selo SHA-256 próprios. Adicionar um novo nunca toca nos existentes.
  • O gerenciador (esta página) fica separado dos códigos, que só entram na tela como texto ou dentro de um quadro isolado.
  • Executar usa um quadro isolado, confere o selo antes e depois e bloqueia a execução se o conteúdo não bater.
  • Só o botão "Substituir conteúdo", na aba daquele código e com confirmação, altera um código guardado.
  • Limites: digitar no campo de texto faz o navegador trocar quebras CRLF por LF. Colar e importar arquivo preservam o original. Em JavaScript, a execução embrulha o código numa página mínima, e o texto guardado continua intacto. Um </script> dentro de um JS guardado como "JavaScript" interrompe a execução; guarde-o como HTML.
